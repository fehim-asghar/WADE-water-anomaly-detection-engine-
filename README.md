# 💧 WADE — Water Anomaly Detection Engine

> **Real-time AI-powered drowning detection system using existing CCTV infrastructure**

### 🏊 The Problem
Drowning is **silent**. No screaming, no splashing — victims bob vertically, go still, and sink. Lifeguards miss it constantly. Over **1,000+ drowning deaths occur in India every year**, many in supervised pools.

### 🧠 The Solution
**WADE** analyzes existing pool/water body CCTV feeds in real-time using computer vision and pose estimation to detect drowning behavior patterns — **before it's too late**.

### ⚡ How It Works
1. 📹 Connects to existing pool CCTV / IP camera streams
2. 🤖 AI detects body pose patterns: vertical orientation, no horizontal movement, repeated submersion, limb stillness
3. 🚨 Instant alarm + exact victim location highlighted on the feed
4. 📊 Admin dashboard with pool zone monitoring, alert history, and response time tracking
